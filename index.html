Konsep IP & Subnetting

IP Address terdiri dari Network ID dan Host ID. Agar dua komputer dapat saling berkomunikasi langsung tanpa router, keduanya harus berada dalam **Network ID yang sama** (satu subnet).

Tantangan Lab: Set PC-1 agar satu subnet dengan Gateway Router (192.168.1.1) dengan Netmask /24!
